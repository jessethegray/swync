[then_after](#then_after), in a written note value instead of bars:
`playn(verse, lead, 4).then_afterd(h, chorus)` leaves half a bar's rest in 4/4.

It takes the values a pattern is written in — `w`, `h`, `q`, `e`, `s`, dotted
with `q.dot`, added together with `h + e` — and how much of a bar one comes to
follows the time signature. A half note is half a 4/4 bar and two thirds of a
3/4 one.

A plain number is refused rather than guessed at: `then_afterd(2, chorus)` has
two readings and the language has a name for each. Write
[then_after](#then_after) for bars or [then_afters](#then_afters) for seconds.

The gap cannot be negative; [overlap](#overlap) is how a section starts early.
